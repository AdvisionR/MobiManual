# General information about MobiVisor

MobiVisor is a Mobile Device Management (MDM) platform. It allows an
administrator to enrol mobile devices, to apply policies to them, and to
distribute applications and configurations from a central web console.

This manual describes the web console. It is written for the administrator who
operates MobiVisor, not for the end user of a managed device.

## Structure of this manual

Each chapter describes one area of the console and follows the same pattern:
what the area is for, how it is reached from the main menu, and the steps to
complete the common tasks in it. Navigation is written as a path, for example
**Users >> Add**, which means: open the *Users* entry in the main menu, then
select *Add*.

## Conventions

| Notation | Meaning |
|---|---|
| **Users >> Add** | A navigation path through the console menu |
| *Save* | A button or control label |
| `admin@example.com` | A literal value to be typed |

## Scope

This manual does not describe the MobiVisor REST API, the internal architecture
of the platform, or the transport used to deliver commands to a device. API
documentation is generated from the API specification and published separately.
