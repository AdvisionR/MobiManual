# Gruppen

Gruppen fassen Geräte zusammen, damit Richtlinien einmal für alle zugewiesen
werden können. Jedes Gerät gehört zu genau einer Gruppe. Ein Gerät kommt in die
Gruppe, die bei seiner Registrierung gewählt wurde, oder in die Gruppe
**Standard**.

## Gruppe anlegen

1. Öffnen Sie **Gruppen** und wählen Sie **Neue Gruppe**.
2. Geben Sie einen Namen und optional eine Beschreibung ein.
3. Wählen Sie **Speichern**.

## Geräte in eine andere Gruppe verschieben

Geräte werden auf der Seite Geräte verschoben: Markieren Sie sie, wählen Sie die
Zielgruppe und dann **In Gruppe verschieben**. Ein verschobenes Gerät verliert
die Richtlinien seiner alten Gruppe und erhält beim nächsten Check-in die der
neuen.

## Richtlinien zuweisen

Wählen Sie unter **Richtlinien** der Gruppe eine Richtlinie und dann
**Richtlinie zuweisen**. Eine Gruppe hat höchstens eine Richtlinie je Typ: Wird
etwa eine zweite Gerätecode-Richtlinie zugewiesen, ersetzt sie die erste.

Richtlinien können auch auf der Seite Richtlinien zugewiesen werden.

## Gruppe löschen

Nur leere Gruppen können gelöscht werden. Verschieben Sie die Geräte vorher. Die
Gruppe **Standard** kann nicht gelöscht werden.
