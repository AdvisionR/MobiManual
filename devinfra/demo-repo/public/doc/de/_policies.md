# Richtlinien

Eine Richtlinie ist eine Sammlung von Einstellungen, die MobiVisor auf alle
Geräte der Gruppen anwendet, denen sie zugewiesen ist. Es gibt drei Typen:
Gerätecode, Kiosk und Einschränkungen. Jeder hat eine eigene Seite.

## Richtlinie anlegen

1. Öffnen Sie **Richtlinien**.
2. Wählen Sie den Typ und dann **Neue Richtlinie**.
3. Benennen Sie die Richtlinie, legen Sie auf der folgenden Seite ihre
   Einstellungen fest und wählen Sie **Speichern**.

## Richtlinie zuweisen

Wählen Sie neben der Richtlinie die Gruppen und dann **Gruppen zuweisen**. Die
Geräte wenden die Richtlinie beim nächsten Check-in an.

Eine Gruppe hat höchstens eine Richtlinie je Typ. Eine zweite Richtlinie
desselben Typs ersetzt in der Gruppe die erste.

## Konformität

Ein Gerät ist konform, wenn es alle Richtlinien seiner Gruppe angewendet hat.
Die Konformität wird bei jedem Check-in geprüft. Nicht konforme Geräte sind auf
der Seite Geräte gekennzeichnet, werden im Dashboard gezählt und nennen auf
ihrem Reiter Übersicht die Gründe.
