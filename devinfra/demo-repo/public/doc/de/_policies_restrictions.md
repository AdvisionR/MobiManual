# Android-Einschraenkungen

Die folgenden Einstellungen werden aus dem Einschraenkungsschema erzeugt.
Bearbeiten Sie das Schema, nicht diese Seite.

| Einschraenkung | Typ | Standard |
|---|---|---|
| `allowCamera` | boolean | `true` |
| `allowScreenCapture` | boolean | `true` |
| `allowFactoryReset` | boolean | `false` |
| `maxPasscodeAgeDays` | integer | `90` |
