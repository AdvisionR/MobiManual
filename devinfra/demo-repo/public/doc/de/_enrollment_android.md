# Android-Registrierung

Android-Geräte werden auf eine von zwei Arten registriert:

- **Vollständig verwaltet**, für Firmengeräte. Das ganze Gerät wird verwaltet.
  Es wird bei der Einrichtung über einen QR-Code registriert.
- **Arbeitsprofil**, für private Geräte. Nur ein getrenntes Arbeitsprofil wird
  verwaltet; die eigenen Apps und Daten des Benutzers bleiben privat.

## Vollständig verwaltete Geräte registrieren

1. Öffnen Sie **Registrierung > Android** und wählen Sie
   **Vollständig verwaltet**.
2. Wählen Sie die Gruppe, in die die Geräte kommen.
3. Wählen Sie **QR-Code erstellen**.
4. Tippen Sie auf einem neuen oder zurückgesetzten Gerät sechsmal auf den
   Begrüßungsbildschirm und scannen Sie den Code.

![](screenshots/_android_qr_code_1.png)

Ein QR-Code kann beliebig viele Geräte registrieren und ist 7 Tage gültig.

## Arbeitsprofil registrieren

1. Öffnen Sie **Registrierung > Android** und wählen Sie **Arbeitsprofil**.
2. Wählen Sie die Gruppe, in die das Gerät kommt.
3. Wählen Sie **Token erstellen** und geben Sie das Token dem Benutzer.
4. Der Benutzer installiert MobiVisor Agent aus Google Play und gibt das Token
   ein.

Ein Token registriert ein Gerät und ist 7 Tage gültig.
