# Benutzer

Die Seite Benutzer listet alle Konten auf, die sich an der Konsole anmelden
koennen.

## Benutzer hinzufuegen

1. Oeffnen Sie **Benutzer** und waehlen Sie **Hinzufuegen**.
2. Geben Sie Anmeldename und E-Mail-Adresse ein.
3. Waehlen Sie eine Rolle. Die Rolle bestimmt, welche Seiten der Benutzer
   oeffnen darf.
4. Waehlen Sie **Speichern**.

![](screenshots/devices_page-should_list_enrolled_devices.png)

## Import aus LDAP

Waehlen Sie **Importieren**, um Konten aus dem konfigurierten Verzeichnis zu
lesen.
