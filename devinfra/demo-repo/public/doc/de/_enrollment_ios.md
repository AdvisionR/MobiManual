# iOS-Registrierung

iOS-Geraete werden ueber Apple Business Manager registriert.

1. Oeffnen Sie **Registrierung > iOS**.
2. Waehlen Sie, ob das Geraet ueberwacht wird.
3. Entscheiden Sie, ob der Benutzer das Verwaltungsprofil entfernen darf.
4. Waehlen Sie **Fertigstellen**, um das Profil zuzuweisen.
