# App-Installationen

App-Installationen bringt Apps auf die Geräte ausgewählter Gruppen. Android-Apps
kommen aus Managed Google Play. iOS-Apps kommen aus dem App Store, mit Lizenzen,
die über Apple Business Manager gekauft wurden.

![](screenshots/_appinstallations_1.png)

## App installieren

1. Öffnen Sie **App-Installationen** und wählen Sie **Neue Installation**.
2. Suchen Sie die App und wählen Sie sie aus.
3. Wählen Sie **Erforderlich** oder **Verfügbar**.
4. Wählen Sie die Gruppen.
5. Wählen Sie **Speichern**.

Eine **erforderliche** App wird automatisch installiert, und der Benutzer kann
sie nicht entfernen. Eine **verfügbare** App erscheint im Katalog von MobiVisor
Agent, und der Benutzer entscheidet, ob er sie installiert.

## Installationsstatus

Jede Installation listet ihre Geräte mit einem Status auf: **Ausstehend**,
**Wird installiert**, **Installiert** oder **Fehlgeschlagen**.

Eine fehlgeschlagene Installation wird dreimal im Abstand von einer Stunde
wiederholt. Schlägt sie danach noch fehl, wählen Sie **Erneut versuchen** neben
dem Gerät.

## App entfernen

Wählen Sie **Von Geräten entfernen**. Erforderliche Apps werden beim nächsten
Check-in deinstalliert. Verfügbare Apps, die Benutzer installiert haben,
bleiben auf ihren Geräten.
