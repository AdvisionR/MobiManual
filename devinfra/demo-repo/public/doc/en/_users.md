# Users

The Users page lists every account that can sign in to the console.

## Adding a user

1. Open **Users** and select **Add**.
2. Enter the login name and the email address.
3. Choose a role. The role determines which pages the user can open.
4. Select **Save**.

![](screenshots/devices_page-should_list_enrolled_devices.png)

## Importing from LDAP

Select **Import** to read accounts from the configured directory. Existing
accounts are matched by login name and are not duplicated.
