# Kiosk Modes

Kiosk mode restricts a device to one application or to a fixed set of them.

![](screenshots/_kiosk_mode_1.png)

1. Open **Policies > Kiosk**.
2. Select **single-app** or **multi-app**.
3. Add the applications the device may run.
4. Select **Save**.

**multi-app** is available on Android only. On iOS, **single-app** needs a
supervised device.

Leaving kiosk mode requires the device passcode.
