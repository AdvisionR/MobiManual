# Devices

The Devices page lists enrolled devices and their current state: name,
platform, owner, group, last check-in and status. A badge marks devices that are
not compliant.

![](screenshots/_devices_1.png)

## Filtering the list

Use the platform filter to restrict the list to Android or iOS. The enrolled
filter hides devices that have been wiped or retired.

The search field matches the device name, the serial number and the owner.

## Acting on several devices

Select devices with the check boxes, then:

- **Move to group** moves them to the group chosen next to the button.
- **Send command** sends a command to all of them. See Device Commands.
- **Retire** removes them from management. Only administrators see this button.

![](screenshots/devices_page-should_list_enrolled_devices.png)

## Exporting the list

**Export CSV** downloads the list as it is currently filtered.

Selecting a device's name opens its detail page.
