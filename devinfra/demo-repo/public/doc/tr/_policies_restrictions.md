# Android Kisitlamalari

Asagidaki ayarlar kisitlama semasindan uretilir. Bu sayfayi degil semayi
duzenleyin.

| Kisitlama | Tur | Varsayilan |
|---|---|---|
| `allowCamera` | boolean | `true` |
| `allowScreenCapture` | boolean | `true` |
| `allowFactoryReset` | boolean | `false` |
| `maxPasscodeAgeDays` | integer | `90` |
